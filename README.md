# OctopusArchive 文件整理工具

Windows 桌面文件整理 GUI 工具，使用 Lazarus（Free Pascal）开发，单 exe 便携运行。

## 语言 / Language

界面支持中文（基准语言）和 English，可通过主窗口右下角的「语言/Language」下拉框切换（跟随系统 / 中文 / English），**下次启动生效**，选择保存在 `octopus_archive.ini` 的 `[Options] Language`（`auto`/`zh`/`en`）。

- `auto`：按 Windows 系统语言自动选择（中文系统 → 中文，其他 → English）
- 翻译文件：`languages/OctopusArchive.en.po`（UTF-8），便携使用时需与 exe 放在同一目录；开发目录下 exe 在 `bin\`，工具会自动回退到项目根的 `languages\`
- 新增语言：新增字符串后先用 `lazbuild` 构建（生成 `lib\**\*.rsj`），再运行 `python tools/gen_po.py` 重新生成 po 模板（自动保留已有翻译），补上新字符串的 msgstr，另存为 `OctopusArchive.<语言代码>.po`，并在 `main.pas` 的 `ApplySavedLanguage` 中增加对应分支

## 功能

所有功能共用顶部**输出目录**设置：留空 = 与源目录相同；填写后，分类/打平产生的目录都建在输出目录下（相对路径按源目录展开，执行时自动创建）。

### 1. 按格式分组（功能①）
- 扩展名统一转小写做目录名：`.JPG` 和 `.jpg` 进同一个 `jpg/` 目录（建在输出目录下）
- 无扩展名文件 → `_noext/` 目录
- 支持映射表：指定哪几种扩展名算一组（如 `jpg,jpeg → 图片`）
  - 目录名留空 = 默认取第一个扩展名
  - 未列出的扩展名自动按自身扩展名建目录，映射表只负责合并与改名
- 隐藏/系统文件默认跳过（可勾选包含）
- 重复执行安全：已在目标位置的文件自动跳过

### 2. 打平目录（功能②）
- 把源目录所有子目录中的文件移动/复制到输出目录顶层；输出目录 = 源目录时顶层文件不动
- 可选"执行（移动）后删除已清空的子目录"，默认不删
- 重名冲突按顶部设置处理

### 3. 按文件名正则分类（功能③）
- 规则列表：正则表达式 + 目标目录名，可增删、上移、下移
- 按列表顺序匹配，**第一个命中的规则生效**
- 匹配对象默认完整文件名（含扩展名），可切换仅主文件名
- 正则默认忽略大小写（可切换）
- 未匹配的文件保持原地不动
- 目标目录名相对输出目录（可含子路径），留空 = 移到输出目录顶层
- 类 PCRE 语法（FPC RegExpr 引擎，按 UTF-8 字节匹配，中文模式可用）

## 安全机制

- **预览**：执行前列出每一行「源文件 → 目标」及状态（待执行/跳过/覆盖/失败），将被覆盖的行标红显示
- **撤销**：每次执行记录操作日志，可一键「撤销本次」（移动恢复原位、复制删除副本；打平删除的空目录会自动重建；执行时新建的分类目录在撤销后若已清空会一并删除）
- **覆盖警告**：覆盖模式执行前弹窗二次确认；**覆盖后的原文件内容无法恢复**
- **后台线程**：扫描/执行/撤销都在后台线程运行，带进度条与取消按钮，不卡界面

## 构建与运行

- 打开 IDE：用 Lazarus 打开 `octopus_archive.lpi`，直接 Run/Build
- 命令行构建：`C:\lazarus\lazbuild.exe -B octopus_archive.lpi`
- 产物：`bin\OctopusArchive.exe`（绿色免安装；English 界面需要 `languages\OctopusArchive.en.po`，发布时与 exe 放同一目录）

## 配置

`octopus_archive.ini` 保存在 exe 同目录（便携式，拷走即带走配置），包含：
- 公共选项（源目录、输出目录、移动/复制、冲突策略、递归、隐藏文件）
- 功能①映射表、功能③正则规则

## 注意事项

- 覆盖模式会真正删除同名目标文件，撤销只能恢复"位置"不能恢复被覆盖的内容
- 任务进行中不能直接关窗，请先点「取消」
- 正则按字节级 UTF-8 匹配，常见中文/数字/通配模式均可用；复杂 Unicode 类别匹配（如 `\p{Han}`）不支持
